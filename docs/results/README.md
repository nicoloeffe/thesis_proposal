# Published Experiment 01 results

This directory contains lightweight, Git-versioned copies of the canonical
reports needed for scientific review. The copies are byte-identical to the
corresponding files under the frozen local `validation/` tree unless a relative
link needed adjustment for publication.

- [`phase1/REPORT_EXPERIMENT_01.md`](phase1/REPORT_EXPERIMENT_01.md): corrected
  Phase I report and narrative changelog;
- [`phase2/REPORT_EXPERIMENT_01_PHASE2.md`](phase2/REPORT_EXPERIMENT_01_PHASE2.md):
  spectral localization report, summary, metadata and figures;
- [`phase3r/REPORT_EXPERIMENT_01_PHASE3.md`](phase3r/REPORT_EXPERIMENT_01_PHASE3.md):
  compute-feasible reader/conditioning diagnostic, protocol amendment and
  figures;
Large Parquet tables, sufficient-statistic arrays, model shards and the
production bundle remain outside Git. `SHA256SUMS` records the integrity of the
publication subset.
